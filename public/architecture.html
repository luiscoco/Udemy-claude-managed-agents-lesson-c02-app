STEP 0 / PREPARE THE MANAGED PATH

Create or reuse the agent and environment

Resource setup is separate from the comparison run. Complete it once, then reuse the IDs.

  1. Configure dependencies and the API key

    From the C02 app directory:

    npm install
if (!(Test-Path .env)) { Copy-Item .env.example .env }

    Set ANTHROPIC_API_KEY in .env. The npm commands load .env into the host process. For a manual-only run, resource creation is not required.

  2. Create the environment, then the custom-tool agent

    Run npm run managed:setup only when new resources are needed. C02 creates the cloud environment first, then registers an agent with the host-side reserveStock custom tool.

  3. Save or override the resource IDs

    Reuse both IDs with a compatible custom-tool agent. Repeating setup creates another environment and agent; a session is created later during a managed run.

  4. Start the comparison application

    npm start

    Open http://127.0.0.1:3000, or the configured PORT. The environment record describes a reusable configuration; creating it alone does not prove a command ran inside a cloud container.
